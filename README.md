# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The player competes against the computer, which randomly selects its move. The game includes animations, score tracking, and a responsive user interface.

---

## 🚀 Features

- 🪨 Play Rock, Paper, Scissors against the computer
- 🤖 Random computer choice generation
- 🎯 Real-time score tracking
- ✨ Smooth hand-shake animations
- 🎨 Attractive and responsive user interface
- ⚡ Fast and lightweight gameplay

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Open the game in your web browser.
2. Click one of the options:
   - 🪨 Stone
   - 📄 Paper
   - ✂️ Scissors
3. The computer will randomly choose its move.
4. The winner is decided based on the classic Rock-Paper-Scissors rules.
5. Scores are updated automatically after every round.

---

## 📜 Game Rules

- 🪨 Stone beats Scissors
- ✂️ Scissors beats Paper
- 📄 Paper beats Stone
- Same choices result in a Draw
